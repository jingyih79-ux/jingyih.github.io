# 黄静仪｜UI/UX 设计师作品集

个人作品集网站，展示沈管家 AI 数字员工、小 E 管家、迅雷云盘用户体验优化、第一现场 APP 与概念性设计作品。

## 本地运行

```bash
pnpm install
pnpm dev
```

## 生产构建

```bash
pnpm build
```

构建结果位于 `dist` 文件夹。项目已使用相对资源路径，可部署在 GitHub Pages 的仓库二级路径中。

## GitHub Pages

仓库包含 `.github/workflows/deploy-pages.yml`。将代码提交到 `main` 分支并在仓库的 **Settings → Pages** 中选择 **GitHub Actions** 后，网站会自动构建并发布。

完整的网页操作说明见 [`docs/GITHUB_PAGES_DEPLOY.md`](docs/GITHUB_PAGES_DEPLOY.md)。

## 隐私说明

公开版本不包含沈管家后台管理界面截图、本地设计过程文件、Vercel 配置或环境变量。
